✨ Overview

AI Tourist Guide is a next-generation full-stack intelligent travel planning platform that transforms how people explore cities.

It enables users to:

🗺️ Discover nearby attractions
🧠 Receive AI-personalized recommendations
📅 Generate optimized itineraries
⚡ Experience real-time updates

All powered by advanced AI and geospatial intelligence.

🎬 3D + Motion UI Experience

The frontend integrates modern motion and immersive UI elements:

✨ Framer Motion Animations – Smooth page transitions
🌌 Parallax scrolling effects
🧊 Glassmorphism UI Design
🎥 3D interactive map using Mapbox GL JS
🌀 Hover-based micro-interactions
💫 Animated recommendation cards
📍 Real-time map pin transitions

Designed to feel futuristic, fluid, and engaging.

🧠 AI Engine

Our intelligent recommendation system integrates multiple advanced techniques:

🤝 Collaborative Filtering

Learns from user behavior

Detects similarity between users

Recommends locations liked by similar travelers

🧠 Content-Based Filtering (TF-IDF)

Uses Natural.js

Analyzes attraction descriptions

Matches user interests with semantic similarity

📐 Constraint Satisfaction

Optimizes itinerary using:

⏳ Time constraints

📍 Distance optimization

🏷️ Category preferences

🛣️ Route efficiency

🚀 Quick Start
1️⃣ Clone Repository
git clone https://github.com/your-username/ai-tourist-guide.git
cd ai-tourist-guide

2️⃣ Backend Setup
cd backend
npm install
cp .env.example .env


Edit .env:

PORT=5000
MONGODB_URI=mongodb+srv://...
JWT_SECRET=your-secret
MAPBOX_ACCESS_TOKEN=pk...


Seed Database:

npm run seed


Start Server:

npm run dev

3️⃣ Frontend Setup
cd frontend
npm install
npm run dev

🔌 API Endpoints
Method	Endpoint	Description
POST	/api/v1/auth/register	Register user
POST	/api/v1/auth/login	Login user
GET	/api/v1/locations/nearby	Get nearby places
GET	/api/v1/recommendations	AI recommendations
POST	/api/v1/itineraries	Create itinerary
POST	/api/v1/itineraries/:id/optimize	AI optimization
